# RoadMate Korea

한국에서 렌터카를 빌린 외국인 운전자에게 한국 교통 규칙을 음성과 자막으로 안내하는 Pleos Connect(Android Automotive) 앱입니다. 운전자의 언어, 평소 운전하던 나라, 한국 운전 경험에 맞춰 안내가 달라집니다. 2026 현대자동차그룹 차량용 앱 개발 공모전 출품작입니다.

**Same Road, Different Guidance.** 같은 길을 달려도 운전자마다 필요한 안내가 다릅니다.

## 해결하려는 문제

외국인 운전자가 빠르게 늘고 있습니다. 2025년 방한 외국인 관광객은 1,894만 명으로 역대 최대입니다([KPMG](https://kpmg.com/kr/ko/insights/eri/2026/issuemonitor-0713.html)). 트립닷컴의 외국인 한국 렌터카 예약은 전년보다 154% 늘었고([여행레저신문, 2026-09-22](https://thetravelnews.co.kr/2026/09/rental-car-travel-self-drive-korea-tripcom-2026/)), 롯데렌탈 단기렌탈 매출의 37%가 외국인 고객입니다(2026년 2분기, [이투데이](https://www.etoday.co.kr/news/view/2611393)).

이 운전자들은 한국의 낯선 규칙을 모르고 달립니다. 빨간불 우회전 때 정지선에서 먼저 멈추기([정책브리핑, 2023-04-21](https://www.korea.kr/news/policyNewsView.do?newsId=148914126)), 어린이보호구역 제한 속도(보통 30km/h, 서울 일부 20km/h, [서울시](https://mediahub.seoul.go.kr/archives/2010924)), 버스전용차로, 하이패스 차로가 대표적입니다. 트립닷컴 예약 증가율 상위 7개국 중 대만을 뺀 6개국은 좌측통행 국가입니다([Wikipedia](https://en.wikipedia.org/wiki/Left-_and_right-hand_traffic)). 구글 지도는 한국에서 자동차 길안내를 하지 않습니다([Orcar](https://orcar.ai/ko/blog/foreigner-ready-jeju-car-rental-guide)).

규칙을 위반하고 출국하면 과태료를 걷지 못합니다. 2021~2025년 외국인 렌터카 과태료 미납액은 16억 9,097만 원입니다([헤럴드경제, 2026-07-14](https://biz.heraldcorp.com/article/10808593), 경찰청 자료). 제주에서는 2025년 보도 기준 최근 5년간 외국인 과태료 14억 9천만 원 중 약 90%를 걷지 못했습니다([제주MBC, 2025-07-15](https://jejumbc.com/NewsArticle/189455)).

렌터카 회사가 외국인 고객을 거절하기도 합니다. 사고가 나면 보험사, 견인 기사, 경찰과 한국어로 통화해야 하기 때문입니다. 2026-11-02에 확인한 제주 업체와 예약 사이트 4곳([제주스타렌터카](https://jejustar.co.kr/rent/rental_info), [제주경매렌터카](https://jejuauction.kr/notice/8), [제주공항렌트카](https://m.jarrent.com/cs/notice_detail.php?id=403), [제주OK렌터카](https://www.jejuokrent.co.kr/home/rentalInfo/list.do), 이용약관 제9조 ⑤)은 모두 외국인에게 "한국어 소통 가능"을 요구하거나, 소통이 어려우면 보험 추가 가입을 요구했습니다. 이 4곳은 해당 조건을 검색해서 찾은 곳이라 업계 전체 비율은 아닙니다.

## 왜 차량 앱이어야 하나

같은 길을 달려도 운전자의 평소 운전 국가와 한국 운전 경험에 따라 설명이 달라집니다. 그 설명이 나오는 시점은 차량 신호가 정합니다.

- 주행 중 오른쪽 방향지시등을 켜고 앞에 우회전이 있으면 빨간불 우회전 규칙을 설명합니다(상세 안내 대상, 반복 제한 적용).
- 내비가 알려 준 앞쪽 단속 카메라로 어린이보호구역 제한 속도를 알았는데 차가 이미 더 빠르면, 구역에 들어가기 전에 "제한 몇, 지금 몇"을 알립니다.
- 기어가 P일 때만 통역과 설정이 열립니다.

차량과 연동되지 않은 일반 폰 앱은 방향지시등과 기어 같은 차량 신호를 읽기 어렵습니다.

운전 중에는 손을 쓰지 않습니다. 안내는 음성과 큰 자막으로 나가고 주행 중 화면은 잠깁니다. 눌리는 것은 음성 질문용 마이크 버튼 하나입니다.

차의 내비와도 함께 동작합니다. 내비가 알려 주는 제한 속도, 단속 카메라, 회전 안내를 받아 그 지점의 한국 규칙을 운전자 언어로 설명합니다. 내비를 앞에 띄워도 안내는 이어집니다.

## 주요 기능

처음 실행하면 2페이지 온보딩이 나옵니다. 첫 페이지에서 언어(English, Français, Español)를 고르고 둘째 페이지에서 평소 운전 국가(11개, 언어로 거르지 않음)와 한국 운전 경험(3개)을 고릅니다. 회원가입 없이 기기에만 저장하고 다음 실행부터는 바로 주행 화면으로 들어갑니다.

개인화 규칙에 따라 좌측통행 국가에서 온 운전자에게는 우측통행 적응 안내를, 좌핸들 차량이 처음인 운전자에게는 좌핸들 적응 안내를 더합니다. 한국 운전 경험이 있으면 기초 설명을 줄입니다. 기타 국가는 통행 방향을 추정하지 않습니다.

주행 중에는 다음 상황에서 안내합니다.

- 어린이보호구역 300m 전에 경고합니다. 제한 속도는 NaviHelper가 준 값을 그대로 씁니다(모든 운전자).
- 경로 안내 없이 달려도 공공데이터의 어린이보호구역 시설 300m 안에 들어오면 알립니다. 위치는 기기 안에서만 비교합니다(모든 운전자).
- 어린이보호구역에 들어가기 전, 앞쪽 단속 카메라로 구역 제한을 알았는데 이미 그보다 빠르면 "곧 어린이보호구역, 제한 몇, 지금 몇"으로 알립니다(모든 운전자).
- 어린이보호구역 안에서 차량 속도가 제한보다 2km/h 넘게 빠르면 지금 속도와 제한 속도를 말하고 계속 빠르면 30초마다 다시 알립니다(모든 운전자). 2km/h는 앱의 판단 여유이며 법적 허용 속도가 아닙니다.
- 우회전 때는 우회전 신호등, 빨간불에서 정지선 앞 일시정지, 보행자 보호를 안내합니다.
- 좌회전 안내에서는 녹색 화살표와 비보호 좌회전 표지가 있을 때의 양보 규칙을 설명합니다.
- 좌핸들 적응 안내는 주행 시작, 좌회전, 차선 변경 때 나옵니다.
- 버스전용차로 단속 지점 300m 전에, 표지판에 적힌 시간에는 들어가지 말라고 알립니다.
- 요금소 500m 앞에서 하이패스 차로는 단말기가 있는 차만 쓴다고 알립니다(상세 안내 대상).
- 구간 단속에서는 시작 지점의 제한 속도를 알리고 구간 평균 속도가 제한을 넘으면 경고합니다(모든 운전자).

안내마다 짧은 요약 카드를 보여 줍니다. 빨간불 우회전, 어린이보호구역, 버스전용차로 같은 교통 상황에는 위에서 본 상황 그림을 함께 넣습니다. 일반 첫 방문 인사와 경험자 인사, 도착 안내는 그림 없이 아이콘과 글로 표시합니다. 음성은 전체 문장을 읽습니다.

음성 질문(Ask RoadMate)은 마이크 버튼을 누르고 자기 언어로 묻는 기능입니다(예: "Can I turn right on red?", "¿Cuál es el límite aquí?"). 답은 규칙 안내 문장을 음성으로 읽고 카드로 보여 줍니다. 우회전, 비보호 좌회전, 어린이보호구역, 버스전용차로, 구간 단속, 지금 도로의 제한 속도(내비 값), "방금 안내 다시"를 물을 수 있습니다. 인식은 Pleos STT가 기기 안에서 하고 질문 문장은 저장하거나 보내지 않습니다.

상황 도움과 사고 대응 화면은 정차 중에 주행 화면의 [도움] 버튼으로 엽니다. 긴급 번호(119 소방과 구급, 112 경찰, 1330 관광 통역 안내)와 사고 때 할 일 4단계(비상등과 안전한 곳으로 이동, 119나 112에 신고, 렌터카 회사 연락, 차를 옮기기 전 사진)를 운전자 언어로 보여 주고 읽습니다. 주변 사람에게 보여 줄 한국어 카드("사고가 났어요. 도와주세요.")는 한국어 음성으로도 읽습니다. 전화 버튼은 번호 입력 화면만 열고 전화를 거는 것은 운전자가 합니다.

통역은 정차 중에 주유소, 주차장, 사고 현장, 렌터카 지점 직원과 이야기할 때 씁니다. 상황별로 미리 번역해 둔 문장 카드 15개는 연결 없이 동작합니다. 카드를 누르면 한국어를 크게 보여 주고 한국어 음성으로 읽습니다. 운전자 말을 한국어로, 직원 말을 운전자 언어로 옮기는 음성 통역은 번역 서버(서버 팀 담당)와 연결해 동작합니다. 제출 APK에는 서버가 연결되어 있지 않아 문장 카드만 씁니다. 서버를 쓰면 번역할 문장, 언어, 상황만 보내고 위치나 주행 기록은 보내지 않습니다. 기어가 P를 벗어나면 듣기를 멈추고 대화를 지웁니다.

주행 화면에는 제한 속도 표지와 지금 속도를 나란히 보여 주고 제한보다 2km/h 넘게 빠르면 빨간색으로 바뀝니다.

내비를 앞에 띄워도 안내가 이어집니다(포그라운드 서비스). 내비와 나란히 띄우는 분할 화면에서는 좁은 화면용 배치로 바뀝니다. 음성은 미디어가 아니라 내비 안내 용도로 재생합니다(시스템이 음악을 멈추는 대신 소리를 줄이는 용도).

주행 중(P가 아닐 때) 화면은 읽기 전용입니다. 설정, 상황 도움, 통역은 정차 중에만 열리고 주행 중에 눌리는 것은 마이크 버튼 하나뿐입니다(Pleos 가이드: 주행 중 음성 입력 허용). 질문을 듣는 동안 안전 경고가 오면 듣기를 멈추고 경고를 먼저 말합니다. 음성은 한 번에 하나만 나가며 위험도가 높은 안내가 먼저입니다. 같은 안내는 반복을 제한합니다. 음성을 쓸 수 없으면 자막으로 대신 보여 줍니다.

주행 화면의 [Play demo: Nakamura]나 [Play demo: Carlos]를 누르면 시연 모드가 실제 SDK와 같은 형식의 주행 신호를 재생합니다. 두 운전자가 같은 길에서 서로 다른 안내를 받는 장면을 보여 줍니다.

## 사업성

로드메이트는 렌터카 회사가 외국인 손님을 받는 부담을 줄여, 렌터카 회사가 Pleos 차량을 들일 이유를 하나 더하는 것을 목표로 합니다.

### 가치 흐름

1. 외국인 렌터카 수요는 늘지만 렌터카 회사는 외국인을 꺼립니다. 사고 때 한국어로 소통해야 하고 출국하면 과태료를 걷기 어렵기 때문입니다(위 [해결하려는 문제](#해결하려는-문제)).
2. 로드메이트를 넣은 차는 외국인 손님을 받는 부담을 줄입니다. 운전자 언어로 한국 규칙을 안내해 몰라서 하는 위반을 줄이는 것이 목표입니다. 사고 때 할 일과 주변 사람에게 보여 줄 한국어 카드도 운전자 언어로 보여 줍니다. 정차 중에는 렌터카 지점이나 주유소 직원에게 보여 줄 문장 카드를 쓸 수 있습니다. 번역 서버를 연결하면 지원하는 언어에서 음성 통역도 됩니다. 다만 보험사나 견인 기사와 한국어로 통화하는 일까지 대신하지는 않습니다. 렌터카 회사가 이 도움을 근거로 "한국어 소통 가능" 조건을 완화할 수 있는지는 시범 운영에서 확인할 가설입니다.
3. 이 기능은 Pleos Connect 차량에서만 동작하므로, 렌터카 회사가 외국인 손님용 차를 고를 때 Pleos 차량을 고를 이유가 하나 늘어납니다. 렌터카 회사가 차를 고르는 주된 기준은 가격, 할인, 중고 매각가입니다. 로드메이트는 조건이 비슷할 때 Pleos 차량을 고를 이유를 더하는 역할입니다.
4. 현대차는 이미 렌터카 회사를 직접 공략하고 있습니다. 2025년 10월 현대캐피탈, 제주특별자치도렌터카조합과 협약을 맺었습니다. 조합 소속 업체가 기준을 채운 차를 팔 때 신차 가격의 최대 65%를 보장합니다([스마트투데이, 2025-10-29](https://www.smarttoday.co.kr/ko-kr/articles/94746)). 2026년 3월에는 신규 렌터카 회사와 중소 렌터카 회사 할인을 전년도 구매 대수와 상관없이 주도록 넓혔습니다([현대자동차그룹, 2026-03-06](https://www.hyundaimotorgroup.com/ko/news/hyundai-motor-rental-car-win-win-promotion)). 로드메이트는 이런 판매 조건에 "외국인 대여 준비"라는 소프트웨어 혜택을 더하자고 제안합니다.
5. 로드메이트를 넣을 수 있는 차는 계속 늘어납니다. Pleos Connect는 2026년 2분기 신차부터 적용되고 2030년까지 2,000만 대가 넘는 차량에 탑재될 계획입니다([한국경제, 2025-03-28](https://www.hankyung.com/article/202503285266g)). 신형 아반떼는 모든 트림에 기본으로 들어갑니다([이투데이, 2026-08-05](https://www.etoday.co.kr/news/view/2611117)). 그랜저와 아반떼에 이어 신형 투싼(2026년 4분기 예정)으로 넓히고 2027년부터 기아 전 차종에도 탑재할 계획입니다([전자신문, 2026-07-26](https://www.etnews.com/20260724000267)). 아반떼는 TMAP 렌터카 서비스에서 가장 인기 있는 차종이었습니다(2023년 1~7월, [테크42](https://www.tech42.co.kr/?p=73962)).
6. 제주의 렌터카 회사 한 곳과 시범 운영해 검증할 계획입니다. 로드메이트를 넣은 차와 넣지 않은 차를 놓고 외국인 대여 건수, 외국인 과태료와 사고 건수를 비교합니다. 렌터카 회사에는 한국어 소통 조건을 완화할 의향이 있는지, 차를 바꿀 때 Pleos 차량을 다시 고를 의향이 있는지 묻습니다.

### 타깃 고객

앱은 외국인 운전자가 쓰고, 렌터카 회사가 차에 넣어 둡니다. 이용료는 현대차가 렌터카 판매 조건에 포함하는 것이 기본안이고 렌터카 회사가 직접 구독하는 것이 대안입니다. 운전자는 처음 한 번 언어, 평소 운전 국가, 한국 운전 경험을 고릅니다. 지금은 프로필을 기기에 저장하므로, 다음 대여자는 정차 중 설정에서 다시 고릅니다.

| 구분 | 누구 | 필요한 것 | 성공 지표 |
|---|---|---|---|
| 사용자 | 국제운전면허로 한국 렌터카를 빌린 외국인 관광객 | 규칙을 몰라 불안하지 않게 운전하기, 여행 뒤 과태료 고지서 받지 않기 | 경고 뒤 감속한 비율, 반납 때 만족도 |
| 도입처 | 렌터카 회사, 특히 공항과 제주 지점 | 사고 같은 긴급 상황에서 외국인 고객과 소통할 수단, 외국인 대여 늘리기 | 외국인 대여 건수, 통역 사용 건수 |
| 제휴처 | 현대차(렌터카 판매) | 렌터카 판매 경쟁력, Pleos 앱마켓의 실사용 사례 | 로드메이트 탑재 렌터카 대수, 렌터카 회사의 Pleos 차량 재구매 |
| 협력자 | 지자체, 경찰, 관광공사, 여행 플랫폼 | 외국인 운전자의 안전, 위반 예방 | 외국인 위반과 사고 건수 |

### 수익 모델

이용료는 차량 1대당 월 7,700원으로 잡았습니다. Pleos Connect 차량의 블루링크 프리미엄(앱마켓 이용)이 5년 무료 기간 뒤 받는 정가를 참고한 제안 가격입니다([현대자동차 블루링크 가입 안내](https://www.hyundai.com/kr/ko/digital-customer-support/app/myhyundai/bluelink-registration)).

기본안(제안)은 현대차가 렌터카 판매 조건에 포함하는 것입니다. 렌터카 회사가 Pleos 차량을 살 때 로드메이트 이용권을 함께 받는 구조로, 위의 렌터카 프로모션과 잔가 보장 같은 판매 조건에 혜택 하나를 더하는 셈입니다. 렌터카 회사는 추가 비용 없이 외국인 대여 준비가 된 차를 얻습니다. 현대차는 할인 금액을 늘리는 대신 외국인 손님 대응이라는 기능으로 판매 조건을 높일 수 있습니다. 이용권 기간과 갱신 방식(예: 연 단위 제휴 갱신)은 현대차와 정할 조건이라 아직 없습니다. 시범 운영 결과를 근거로 제안할 부분입니다.

대안은 렌터카 회사가 직접 구독하는 것입니다. 2023년 롯데렌터카 기준으로 외국인은 대여 1건에 평균 36만 원을 쓰고 평균 3일 16시간을 빌렸습니다([아시아투데이, 2023-10-17](https://www.asiatoday.co.kr/kn/view.php?key=20231017010008378)). 구독료는 이 한 건에 비해 작은 금액입니다. 외국인 고객에게 하루 5,000원 옵션으로 팔 경우, 고객이 옵션을 사면 한 건에 약 1만 8,000원으로 한 달 구독료의 두 배가 넘습니다. 앱을 무료로 제공해 외국인 대여가 한 건 더 생긴다고 가정하면, 그 한 건의 영업이익(롯데렌탈 단기렌탈 영업이익률 12.6~18.9% 기준 4만 5천~6만 8천 원, [서울경제](https://m.sedaily.com/article/14139550), [이투데이](https://www.etoday.co.kr/news/view/2611393))이 구독료 약 5.9~8.8개월분입니다. 이 가정도 시범 운영으로 확인할 부분입니다.

지자체와 경찰도 고객이 될 수 있습니다. 걷지 못하는 과태료를 쫓는 것보다 위반을 미리 막는 편이 행정에도 낫습니다. 외국인 교통안전 사업으로 도입비를 지원받는 방식을 생각하고 있습니다.

### 예상 MAU

MAU는 한 달 동안 로드메이트를 쓴 외국인 운전자 수입니다. 아직 측정 전인 목표치입니다. 대여 1건을 1명으로, 대여한 운전자는 모두 앱을 쓰는 것으로, 같은 달 중복 대여는 없는 것으로 단순화했습니다. 월 이용료는 현대차와 렌터카 회사 중 누가 내든 그해 모든 탑재 차량에 표시 가격을 청구한다고 본 금액입니다. 서버와 운영 비용을 뺀 이익은 아닙니다.

| 연도 | 탑재 차량(목표) | 목표 MAU | 월 이용료(대당 7,700원) |
|---|---|---|---|
| 2027 | 1,000대 | 1,000명 | 770만 원 |
| 2028 | 5,000대 | 6,000명 | 3,850만 원 |
| 2029 | 1만 5,000대(제주 밖 포함) | 1만 2,000명 | 1억 1,550만 원 |

기준은 롯데렌터카 한 곳의 월 외국인 대여 건수입니다. 2026년 1분기 외국인 단기 렌터카 매출은 66억 원입니다([MTN, 2026-07-16](https://news.mtn.co.kr/news-detail/2026071616420877169)). 66억 원 ÷ 대여 1건 36만 원 ÷ 3개월 = 월 약 6,100건입니다(두 숫자의 시점이 달라 근사치). 2028년 목표는 이 규모, 2029년 목표는 그 두 배입니다. 탑재 차량 1대당 한 달에 앱을 쓰는 외국인 대여를 1.0건(2027), 1.2건(2028), 0.8건(2029)으로 가정했습니다. 2029년은 외국인 비중이 제주보다 낮을 수 있는 다른 지역을 포함해 낮춰 잡았습니다.

차량 대수로 보면 제주 렌터카는 2만 9,782대입니다([파이낸셜뉴스, 2026-09-16](https://www.fnnews.com/news/202609161113385398)). 2028년 5,000대는 그 17%입니다. 초기 목표는 Pleos 탑재 렌터카가 아직 적다는 점을 반영했습니다. 렌터카 회사의 차량 교체 계획은 확인이 필요합니다. 신형 아반떼부터 Pleos Connect가 기본으로 들어가므로([이투데이, 2026-08-05](https://www.etoday.co.kr/news/view/2611117)), 렌터카 회사가 차를 바꿀수록 설치할 수 있는 차가 늘어납니다.

### 리텐션

렌터카 회사와 현대차에서 나오는 앱 수익은 기본안과 대안 모두 연간 매출 유지율(Gross Revenue Retention) 90% 이상을 목표로 합니다. 기본안은 현대차와의 제휴를 해마다 갱신하는지와 이용권이 적용된 차량에 계속 이용료가 청구되는지로, 대안은 렌터카 회사의 분기 구독 갱신으로 잽니다. 근거는 2025년 B2B SaaS 기업 1,000여 곳의 중앙값 91%와 월 단위 계약의 중앙값 89%입니다([SaaS Capital, 2025](https://www.saas-capital.com/wp-content/uploads/2025/09/RB32WS1-2025-B2B-SaaS-Retention-Benchmarks.pdf)). 렌터카 회사가 차를 바꿀 때 다시 Pleos 차량을 고르는지(재구매)는 현대차가 보는 제휴 가치 지표로 따로 둡니다. 갱신할 이유가 되는 외국인 대여 건수와 통역 사용 건수는 지점별 집계로 보여 줄 계획입니다. 위치나 주행 기록 원본은 넘기지 않습니다.

외국인 운전자에게 로드메이트는 대여 기간(평균 3일 16시간) 동안 차를 탈 때마다 쓰는 앱입니다. 설정은 처음 한 번만 하고 이후에는 주행 화면으로 바로 들어갑니다. 운전자 쪽 지표는 이틀 이상 대여한 건 중 앱을 이틀 이상 쓴 비율로 잴 계획입니다. 다음 방문 때 같은 렌터카 회사를 다시 고르는 데 도움이 되는지도 검증할 부분입니다.

### 확대 계획

언어는 지금 영어, 프랑스어, 스페인어입니다. 규칙 판단과 문구를 분리해 두어 언어를 늘리는 부담을 줄였습니다. 일본어와 중국어는 Pleos 음성 엔진 지원을 확인한 뒤 언어 선택, 음성 로케일, 음성 질문 인식, 번역 서버 지원을 함께 추가합니다.

여행 플랫폼 제휴로 트립닷컴, 클룩의 렌터카 상품에 "로드메이트 탑재 차량"을 표시해 렌터카 회사의 예약을 늘립니다.

다른 나라의 Pleos 탑재 차로 넓힐 때 차량 신호 처리, 음성 큐, 안내 카드 구조는 그대로 씁니다. 다만 지금 판단 정책은 한국 운전을 전제로 합니다(한국 운전 경험, 우측통행 적응). 그래서 운전하는 나라별로 통행 방향, 경험 기준, 교통 규칙 판단을 분리해야 합니다. 그 나라의 법규 검증, 위치 데이터, 내비 이벤트 확인도 거칩니다.

2025년 10월 경찰청은 중국 면허를 인정하는 방안을 검토한다고 밝혔습니다([뉴시스, 2025-10-16](https://www.newsis.com/view/NISX20251016_0003365627)). 제도가 바뀌어 허용되면 중국인 관광객도 고객이 됩니다.

지역은 제주 시범 운영 뒤, 현대차의 제주 렌터카조합 협약처럼 지역 조합 단위로 공항 지점이 많은 지역부터 넓힙니다.

## 구조

교통 상황 판단 로직, 언어별 문구, 음성 출력을 분리했습니다.

```
Vehicle/NaviHelper/FusedLocation SDK ─┐
                                      ├─ RawSignal ─ SignalMapper ─ DriveEvent ─ GuidanceEngine ─ 안내 ID
DemoRoute(시연) ──────────────────────┘                    공공데이터 시설 좌표 ─┘         │
                                                  문구 리소스(en, fr, es, ko) ─ GuidanceSpeaker ─ Pleos TTS
                                                                                  └─ 화면 자막
```

- `rules/`: Android import 없는 순수 Kotlin 판단 로직과 단위 테스트
- `i18n/`, `res/values*`: 언어별 문구
- `voice/`: Pleos TTS, 음성 큐
- `vehicle/`, `navi/`, `location/`, `drive/`: SDK 어댑터와 신호 변환, 주행 세션, 포그라운드 서비스
- `interpreter/`: 정차 중 통역. 문장 카드와 번역 서버 연결
- `demo/`: 시연 경로와 페르소나
- `ui/`: 온보딩, 주행 화면, 상황 도움과 통역(`ui/help/`), 상황 그림(`ui/scene/`)

## 사용한 Pleos Connect SDK

| SDK | 버전 | 용도 | 권한 |
|---|---|---|---|
| Vehicle | 2.3.2 | 기어, 방향지시등 | `CAR_DRIVE`, `CAR_LIGHTS` |
| NaviHelper | 3.0.5 | 제한 속도, 어린이보호구역, 단속 카메라, 회전 안내, 도착 | `NAVI_ROUTE`, `NAVI_ROUTE_SEARCH` |
| TextToSpeech | 3.3.1 | 음성 안내(ON_DEVICE) | `TTS_SERVICE` |
| SpeechToText | 3.3.1 | 음성 질문, 통역(ON_DEVICE, en-US, fr-CA, es-US, ko-KR) | `STT_SERVICE`, `RECORD_AUDIO`(정차 중 한 번 요청, 거부하면 마이크 버튼을 숨김) |
| FusedLocation | 1.1.3 | 공공데이터 어린이보호구역 시설과 견줄 차 위치 | `FUSED_LOCATION`(정차 중 한 번 요청, 거부하면 이 알림만 빠짐) |

TTS 로케일은 Pleos 온디바이스 엔진이 지원하는 en-US, fr-CA, es-US, ko-KR을 씁니다.

Pleos SDK 밖에서 쓰는 기능:

| 기능 | 용도 | 권한 |
|---|---|---|
| Android Automotive `CarPropertyManager` | 차량 속도(`PERF_VEHICLE_SPEED`). Vehicle SDK에 속도 API가 없음 | `android.car.permission.CAR_SPEED`(정차 중 한 번 요청, 허용 창에는 "위치 정보"로 표시) |
| 포그라운드 서비스 | 내비를 앞에 띄워도 안내 유지 | `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `POST_NOTIFICATIONS` |

차량 속도와 위치는 기기 안에서만 쓰고 외부로 보내거나 기록하지 않습니다. 위치는 앱에 넣어 둔 어린이보호구역 시설 좌표와 견주는 데만 씁니다. 속도 권한을 거부하면 현재 속도 표시와 어린이보호구역 과속 경고가 빠집니다. 구간 단속 평균 속도 경고를 비롯해 내비 신호를 쓰는 나머지 안내는 그대로 나갑니다.

## 데이터 출처

- 어린이보호구역 시설 좌표: 공공데이터포털 [전국어린이보호구역표준데이터](https://www.data.go.kr/data/15012891/standard.do)의 지자체별 파일. `tools/school-zones/fetch.py`로 받고 `build.py`로 위도와 경도만 남겨 `app/src/main/assets/school_zones.csv`에 넣었습니다. 시설 이름과 주소는 넣지 않았습니다. 좌표가 시설 위치라서 구역 경계까지의 거리는 말하지 않습니다.

## 빌드

요구 사항: Android Studio, Android SDK Platform 35. Gradle은 `gradle/gradle-daemon-jvm.properties`에서 JDK 21로 돌도록 정해 두었습니다. 최신 Android Studio에 내장된 JDK 25로 실행해도 Gradle이 설치된 JDK 21을 찾아 씁니다. 없으면 내려받아 씁니다.

```bash
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # 개발용(한국어와 확인용 화면 포함)
./gradlew assembleRelease     # 제출용
```

## 실행

Pleos Connect Emulator 2.1.0(Android Studio SDK Manager)에서 실행합니다. 일반 안드로이드 폰에서는 Pleos 차량 서비스가 없어 동작하지 않습니다.

```bash
adb install -r dist/roadmate-korea-1.2.0.apk
```

1. 온보딩에서 언어, 국가, 경험을 고르고 START를 누르면 시작 음성이 나옵니다.
2. 주행 화면에서 [Play demo: Nakamura] 또는 [Play demo: Carlos]를 누르면 시연 경로가 재생됩니다.
3. 실제 신호로 확인하려면 `adb forward tcp:8088 tcp:8088`을 실행한 뒤 `http://127.0.0.1:8088/`에서 Pleos Virtual Console을 열고 기어, 방향지시등, 속도를 바꿉니다.
4. 내비와 함께 보려면 앱 영역 오른쪽 끝 손잡이를 끌어 내비와 RoadMate를 나란히 띄웁니다.
5. 정차(P) 중에 [도움]을 누르면 상황 도움, 사고 대응, 통역 문장 카드를 볼 수 있습니다.
6. 위치 기반 어린이보호구역 알림은 기어를 D로 두고 `adb emu geo fix <경도> <위도>`로 학교 근처(예: `127.0154 37.4885`, 서울교대부설초 남쪽 약 250m)로 옮기면 들을 수 있습니다.

제출용 APK는 `dist/` 폴더에 있습니다.

### 통역 번역 서버 연결(roadmate-AI)

제출 APK에는 서버 주소가 없어 통역은 문장 카드로만 동작합니다. 음성 통역은 로컬 LLM 번역 서버인 [roadmate-AI](https://github.com/roadmate-korea/roadmate-AI)와 연결해 씁니다.

1. 에뮬레이터를 돌리는 PC에서 roadmate-AI를 `127.0.0.1:8000`으로 실행합니다. 모델 없이 연결만 확인하려면 모의 모드(`start_all.ps1 -Mock`, `run.sh start --mock`)를 씁니다.
2. 서버 주소를 넣어 빌드합니다. 에뮬레이터에서 `10.0.2.2`는 그 PC를 가리킵니다.
   ```bash
   ./gradlew assembleDebug -Proadmate.serverUrl=http://10.0.2.2:8000
   ```
3. 통역 화면에서 마이크를 누르면 음성 인식(Pleos STT) → 번역 서버 → 음성(Pleos TTS) 순서로 동작합니다.

- 번역 서버는 영어와 한국어, 스페인어와 한국어 사이만 번역합니다. 프랑스어 프로필은 말하기 전에 "음성 통역은 아직 이 언어를 지원하지 않음"을 알리고 문장 카드를 쓰게 합니다.
- 서버가 다시 말해 달라고 답하면 "더 짧고 쉽게 다시 말해 주세요"를 보여 줍니다.
- 서버에는 번역할 문장, 언어, 상황만 보내고 위치나 주행 기록은 보내지 않습니다. 앱의 시간 제한이 3초라서 서버는 `MODEL_TIMEOUT_S=2.5`로 실행하기를 권합니다(roadmate-AI README).

## 확인한 것과 남은 것

에뮬레이터에서 확인한 것:

- 온보딩과 저장, 4개 언어 TTS 재생, 실제 기어와 방향지시등 신호로 나오는 시작 안내와 회전 안내, 주행 중 잠금, 두 페르소나 시연 전체
- Virtual Console로 넣은 속도의 화면 표시, 내비를 앞에 띄운 상태의 안내 재생, 분할 화면 배치(영어, 프랑스어, 스페인어)
- 음성 질문과 통역의 음성 인식(마이크가 없어 합성 음성 PCM을 넣어 확인), 상황 도움과 사고 대응 음성, FusedLocation 위치로 학교 근처 어린이보호구역 알림

남은 것:

- 실제 NaviHelper 경로 안내로 받은 어린이보호구역, 카메라, TBT 이벤트는 아직 확인하지 못했습니다. 대신 시연 모드와 단위 테스트로 검증했습니다.
- 실제 사람 목소리와 차량 소음 속의 음성 인식, 통역 문장 카드의 원어민 감수, 번역 서버 연결은 아직입니다.
- 실차 확인은 하지 않았습니다.
